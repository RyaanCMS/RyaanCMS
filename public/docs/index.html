Overview

RyaanCMS is the World's First AI-Powered Free & Opensource CMS & EMS. It lets you build complete, production-ready applications from a single natural-language prompt — using AI models like Claude, GPT-4, Gemini, Mistral, and local Ollama.

RyaanCMS is self-hosted on any PHP server. You own your data, your code, and your infrastructure.

✓ What it is

  • AI-powered application builder
  • Multi-provider AI (21 providers)
  • Plugin marketplace (install & sell)
  • Menu & navigation management
  • Self-hosted, MIT licensed

📋 Requirements

  • PHP 8.2+
  • MySQL 8+ or MariaDB 10.4+
  • Composer 2.x
  • Node.js 18+ & npm
  • Laravel 11

Installation

1. Clone & Install Dependencies

git clone https://github.com/your-org/ryaancms.git
cd ryaancms
composer install
npm install && npm run build

2. Environment Setup

cp .env.example .env
php artisan key:generate

Edit .env and set your database credentials:

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=ryaancms
DB_USERNAME=root
DB_PASSWORD=your_password

3. Database Migration

php artisan migrate

4. Web-Based Wizard

Navigate to https://your-domain.com/install and follow the setup wizard to create your admin account and configure the application.

5. AI API Keys

After logging in, go to Settings → AI Providers and add your API keys for whichever AI services you want to use.

You can use Ollama for completely free local AI with no API key required. Install Ollama on your server and set the API URL to http://localhost:11434.

AI Builder

The AI Builder is the core of RyaanCMS. Access it at /builder/{project-id}.

Layout (3-Panel)

PanelPositionContent
Prompt / AI ChatLeft (w-96)Chat with AI, send prompts, attach files/URLs, voice input
Code Editor + PreviewCenter (flex-1)Monaco-style code editor, live HTML/Blade preview, split view
File TreeRight (w-64)All project files, create/delete files and folders

View Modes

  • Code — Full-width code editor only
  • Split — Code editor left, preview right (default)
  • Preview — Full-width live preview

Preview System

The preview iframe supports:

  • .html / .htm — Rendered directly
  • .blade.php — PHP/Blade server-side code is stripped; HTML structure is shown
  • Auto-refresh after AI generates files
  • Auto-refresh after saving a previewable file

Multi-Input Support

  • 📎 File attachments (images, PDF, Word, Excel, code files, etc.)
  • 🌐 URL content reading (paste a URL, AI reads the page)
  • 🎤 Voice input (Web Speech API — Chrome/Edge)

Projects

Projects are the top-level container for AI-generated applications. Each project has:

  • A type (laravel, react, nextjs, ecommerce, crm, saas, etc.)
  • A status (active, archived, etc.)
  • Files — all generated source files
  • AI Conversations — chat history per session
  • Token tracking — ai_tokens_used

Projects can be exported as .zip packages via the Package feature (/projects/{id}/package).

Marketplace

The marketplace allows installing pre-built modules, plugins, themes, and AI agents into your projects.

Installation Types

  • Browse & Install — Install from the marketplace catalog
  • Upload & Install — Upload a downloaded .zip package directly

Marketplace Categories

eCommerce · CRM · HRM · Accounting · AI Agents · Themes · Utilities · Integrations · Templates

Developer Revenue

Developers earn 70% revenue share on paid marketplace items. Submit your module via Marketplace → Submit Item.

Menu Management

Menu Management allows creating and managing navigation menus for your site. Access at /menus.

Menus

A Menu has:

FieldTypeDescription
namestringDisplay name (e.g. "Main Navigation")
slugstringAuto-generated unique identifier
categoryheader|footer|sidebar|customWhere this menu is used
is_activebooleanWhether the menu is published

Menu Items

Each menu can have nested Menu Items:

FieldTypeDescription
labelstringLink text
urlstringDestination URL (manual or auto-filled from plugin)
iconstringEmoji icon (optional)
target_self|_blankLink target
parent_idint|nullParent item ID for nesting
installation_idint|nullLink to installed marketplace plugin
orderintDisplay order

Plugin Assignment

When adding or editing a menu item, you can select an installed marketplace plugin from a dropdown. This automatically fills the URL field with the plugin's route, creating a direct link from your menu to an installed module.

Settings

AI Providers

Connect up to 21 AI providers. Each provider stores an API key (encrypted), optional API URL, and default model. One provider can be set as the system default.

Profile & Password

Update your name, email, username, and password.

Preferences

Set theme (light/dark), default AI provider, default model, and language.

Branding

Upload a custom logo/favicon and set primary brand color and font family.

API Reference

All API endpoints require authentication unless noted. Include the session cookie or pass X-CSRF-TOKEN header for state-changing requests. For JSON responses, include Accept: application/json.

Authentication

POST /login

Request Body

{ "email": "user@example.com", "password": "secret" }

Response

Redirects to /dashboard on success. Returns 422 with validation errors on failure.

POST /register

Request Body

{ "name": "John", "email": "john@example.com", "password": "secret", "password_confirmation": "secret" }
POST /logout Auth

Logs out the current user and invalidates the session.

Projects API

All routes require Auth.

GET/projects

Returns paginated list of the authenticated user's projects.

POST/projects
{ "name": "My App", "type": "laravel", "description": "..." }

Creates a new project. Returns redirect to project detail.

PUT/projects/{project}/settings

Update project name, type, description, status.

DELETE/projects/{project}

Permanently deletes project and all associated files.

GET/projects/{project}/package

Download project as a .zip archive.

Builder API

All routes require Auth. JSON requests require Content-Type: application/json and Accept: application/json.

POST/builder/{project}/chat

Request (JSON)

{
  "message": "Create a Hotel Management System with rooms and bookings",
  "conversation_id": 1,
  "provider": "claude",
  "model": "claude-sonnet-4-6"
}

Request (Multipart — with file/URL attachments)

FormData:
  message: string
  conversation_id: int
  provider: string
  model: string
  url?: string           // website URL to read
  files[]?: File[]       // uploaded files

Response

{
  "success": true,
  "message": "AI response text...",
  "model": "claude-sonnet-4-6",
  "files_generated": [
    { "id": 1, "name": "index.html", "path": "index.html", "type": "file" }
  ]
}
GET/builder/{project}/files/{file}

Returns file content.

{ "content": "" }
PUT/builder/{project}/files/{file}
{ "content": "updated file content" }
POST/builder/{project}/files
{ "path": "app/Models/Room.php", "type": "file" }
DELETE/builder/{project}/files/{file}

Deletes a file or folder from the project.

POST/builder/{project}/conversations
{ "provider": "claude" }
// Response: { "success": true, "conversation": { "id": 2, ... } }

Marketplace API

GET/marketplace

Browse marketplace catalog. Supports search and category filters via query params.

POST/marketplace/{item}/install

Install a marketplace item for the current user.

{ "project_id": 1 }   // optional: associate with a project
POST/marketplace/upload-install

Upload and install a .zip package directly.

FormData: { file: .zip }
POST/marketplace/activate/{installation}

Activate an installed item.

Menus API

All routes require Auth. Menus are scoped to the authenticated user.

GET/menus

List all menus for the current user.

POST/menus

Request

{ "name": "Main Navigation", "category": "header" }

Validation

FieldRules
namerequired, string, max:100
categoryrequired, in: header|footer|sidebar|custom
PUT/menus/{menu}
{ "name": "Updated Name", "category": "footer", "is_active": true }
DELETE/menus/{menu}

Deletes menu and all its items (cascade).

POST/menus/{menu}/items

Request

{
  "label": "Home",
  "url": "/",
  "icon": "🏠",
  "target": "_self",
  "parent_id": null,
  "installation_id": null   // optional: link to installed plugin
}
If installation_id is provided and url is empty, the URL is auto-filled from the plugin's marketplace route.
PUT/menus/{menu}/items/{item}

Update a menu item. Same fields as store.

DELETE/menus/{menu}/items/{item}

Delete a menu item. Child items are cascade-deleted.

POST/menus/{menu}/items/reorder
{ "items": [3, 1, 4, 2] }   // ordered array of item IDs

Returns {"success": true}.

Settings API

POST/settings/ai-providers

Request (JSON)

{
  "provider": "claude",
  "api_key": "sk-ant-...",
  "api_url": null,
  "default_model": "claude-sonnet-4-6",
  "set_default": true
}

Response (JSON)

{ "success": true, "message": "Claude connected successfully!", "provider_id": 1 }
DELETE/settings/ai-providers/{aiProvider}

Returns {"success": true} when called with Accept: application/json.

POST/settings/ai-providers/test
{ "provider": "claude" }
// Response: { "success": true, "message": "RyaanCMS connection test successful!", "model": "..." }
